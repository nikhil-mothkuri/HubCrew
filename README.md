# HubCrew Talent Solutions

Modern, Apple-inspired digital presence and recruitment platform for **HubCrew Talent Solutions LLP** (Hyderabad, India).

## 🚀 Features
- **7 Practice Units:** Enterprise RPO, Tech & Engineering, Executive Search, Contract Staffing, Campus Hub, HR Advisory & Compliance, GCC Hub Setup (BOT).
- **Technology Hiring Matrix:** Dedicated sourcing pods for Engineering, Product, AI/Data, Cloud/DevOps, and UI/UX Design.
- **Interactive Visualizations:**
  - 5-Stage Recruitment Lifecycle Process Stepper ("How We Work")
  - Interactive Tech Stack Ecosystem Radar
  - Strategic Model Comparison Matrix (Embedded RPO vs Traditional Contingency vs In-House TA)
  - Talent Cost & ROI Calculator
- **Apple-Inspired Design System:** Translucent frosted glass navigation, San Francisco typography, segmented Dark/Light mode switcher with persistence.
- **Digital Business Cards:** Interactive vCard export for founders (**Krishna Saurabh** & **Rini Shah Purohit**).
